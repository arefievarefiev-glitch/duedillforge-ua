# Результат агента

- Результат — один JSON-файл за шляхом із завдання. Запиши його цілком, за один раз.
- Нічого іншого не створюй: ні markdown-версії, ні файлу нотаток. Усі зрозумілі людині документи формує програма з твого JSON.
- Тільки чинний JSON: без коментарів, кінцевих ком, обгортки markdown і тексту до чи після об'єкта.
- Назви полів і значення переліків бери з завдання дослівно. Невстановлене значення — `null` або порожній рядок, а не вигадане.
- Текстові поля пиши українською, за `lib/prose-style-uk.md`.
- Перед записом результату не повторюй міркувань у видимому виводі. Після запису відповідай одним рядком: «готово».
