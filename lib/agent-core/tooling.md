# Інструменти

- Керування перевіркою — через `ddf` (шлях і ідентифікатор завдання наведено в завданні). Команди пишуть один JSON-об'єкт у stdout.
- Файли з робочої теки читай через Read, але `state.json`, `ledger/`, `register.json`, `docs.json` вручну не редагуй: їх веде програма.
- Тексти документів і законів у робочій теці читай лише через `ddf evidence units|cut|scan|locate`. Читання файлу з `texts/` напряму не фіксується в журналі читань і не дає підстави для статусу «Не виявлено».
- Інтернет (WebSearch, WebFetch) для документів об'єкта заборонений. Для норм, яких немає в блокноті законодавства, дозволений лише Legal Data Hunter (агент `legal-basis-researcher`).
- Помилка `ddf` із полем `error` — не привід вигадувати результат. Прочитай поле, виправ виклик, повтори один раз; якщо помилка лишилась, повернь позицію зі статусом `unverified` і описом у `detail`.
